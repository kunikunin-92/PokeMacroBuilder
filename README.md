# PokeMacro Builder

Poke-Controller(pokecon)用のマクロを、Scratch風のコードブロックで作成できる Windows デスクトップアプリです。
ボタン入力・押す時間・待機・**同時押し**に対応しています。

## 開発環境 / テンプレート

- **Visual Studio Community 2022**
- 新しいプロジェクト → **「WPF アプリ」(C#)** を選択（.NET 8）
  - ※「WPF アプリ (.NET Framework)」ではなく、**.NET 版の「WPF アプリ」** を選んでください。
  - WinForms ではなく WPF を採用している理由：スティック風のブロックUI・ドラッグ操作・VS風のダーク
    テーマを、データバインディングとスタイルで素直に実現できるためです。

既にプロジェクト一式があるので、`PokeMacroBuilder.sln` をダブルクリックで開けば F5 で実行できます。

## 使い方

1. 起動したら **「フォルダを選択...」** で pokecon（Poke-Controller）のフォルダを選択。
   - ルートでも `SerialController` でも、配下に `PythonCommands` があれば自動認識します。
   - 前回のワークスペースは自動で記憶されます。
2. 本ツールで作成済みのマクロは一覧に自動表示されます（ダブルクリックで再編集）。
3. **「新規作成」** → 表示名を入力 → ブロック編集画面へ。
4. 左パレットのブロックをクリックして追加：
   - 🎮 **ボタンを押す**（押す時間 / 待機を指定）
   - 🔗 **同時押し**（複数キーを同時に）— 各ブロックで「キー追加」しても同時押しにできます
   - ⏱ **待機する**
   - ▲▼ で並べ替え、ドラッグでも移動できます。上部で「繰り返し（無限／回数）」も設定可。
5. **「保存」** で `PythonCommands/MacroBuilder/macroN.py` として保存されます。

## 仕様メモ

- 入力した名前は **表示名**（Python の `NAME` 属性）。実ファイル名は `macro1.py` のように自動採番。
- 生成 `.py` の先頭コメントに編集情報を埋め込み（`# PMB-DATA:...`）。この行があるファイルを
  「本ツール製マクロ」として一覧取得・再編集します（手動で書き換えないでください）。
- 出力形式は Poke-Controller 標準の `PythonCommand`（`self.press(...)` / `self.wait(...)`）。
